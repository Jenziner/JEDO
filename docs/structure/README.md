 # Sizing
 ## Definition of a AGER
 - 2-4 peer nodes, 1 State Database (5-10GB) > 4000-5000TPS > more than 10'000'000 HUMAN possible (4tx per day when 30% daily in 1 Peak-Hour)
 - CouchDB not more than 500'000 UTXO accounts > 20% active user results in a 5-10 GB database
 **max 1'000'000 HUMAN per AGER**

 ## Definition of a REGNUM
 - max Orderer-Nodes: 10
 - max Peer-Nodes: 200
 - max Organisations @ 4 Nodes: 50 / @ 2 Nodes: 100
 **max 80 AGER per REGNUM**
